# HumanAAVProject

Codebase for the McGinnis lab's AAV-delivered cell-type-specific enhancer therapy work (currently focused on GBM).

## Active release

**GBM Enhancer Atlas** — harmonized human glioblastoma chromatin accessibility atlas (snATAC-seq, 48 patients, 8 cohorts, 1.52M nuclei).

- Code, docs, tests: [`Glioblastoma snATACseq pipeline/analysis_2026-10-11/`](Glioblastoma%20snATACseq%20pipeline/analysis_2026-10-11/)
- Data artifacts (peak reference, pseudobulk matrix, scored reports): Zenodo DOI [10.5281/zenodo.23252324](https://doi.org/10.5281/zenodo.23252324)
- Release tag: `v2026-10-11`

See the atlas subdirectory's [README](Glioblastoma%20snATACseq%20pipeline/analysis_2026-10-11/README.md), [SCHEMA](Glioblastoma%20snATACseq%20pipeline/analysis_2026-10-11/SCHEMA.md), [CHANGELOG](Glioblastoma%20snATACseq%20pipeline/analysis_2026-10-11/CHANGELOG.md), and [HOW_TO_WORK](Glioblastoma%20snATACseq%20pipeline/analysis_2026-10-11/HOW_TO_WORK.md) for the full picture.
