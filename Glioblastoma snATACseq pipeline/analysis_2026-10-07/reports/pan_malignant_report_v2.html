Pan-malignant AAV enhancer candidates — GBM atlas v2 (2026-10-07)

Source atlas: 8 cohorts, 51 patients, 1,523,668 nuclei. Pan-malignant pool built from malignant_cnv == 1 OR cell_type == malignant_unresolved, which recovered 438,994 CNV-malignant cells in GBM-Space that marker-peak scoring had mis-assigned to TME types.

What changed from v1

  1. Fixed nearest-gene bug — pyranges was returning 29 Mb-distant pseudogenes when protein-coding genes were within kb. Rewrote with manual TSS binary search.
  2. Added selectivity-vs-non-malignant — now reports how many × more open each peak is in malignant cells vs. the best-matched non-malignant cell type from the main cell-type matrix. Critical for AAV cell-type selectivity.
  3. Added distal + housekeeping filters — the AAV cloning shortlist now excludes promoters (|d|<2 kb from TSS, which drive broad expression) and housekeeping genes (MCM3, VCP, CCT8 etc., open in every proliferating cell).
Important caveat. The v1 top-15 was dominated by promoter-proximal peaks (PRKCSH, FEM1A, UBAP2, MCM3, VCP, STAT2…). These are housekeeping promoters, open in every proliferating cell — exactly what you DON'T want for AAV cell-type-selective targeting. v2 filters them out so the shortlist actually reflects distal, malignant-selective enhancer candidates.

Caveats / limits of this analysis

  • chr7 excluded on principle. chr7+ gain is universal in GBM, so chr7 peaks have inflated strength from CNV, not cell-type selectivity. Even if a chr7 peak is in a biologically perfect spot, re-ranking against a CNV-matched reference is required before trusting it.
  • Selectivity reference is coarse. We compare malignant strength to the max strength across non-malignant cell types (TAM, neuron, OPC, microglia, etc.). A peak that's very open in e.g. neurons will score poorly on selectivity even if it's clearly tumor-driving in a non-neuron context.
